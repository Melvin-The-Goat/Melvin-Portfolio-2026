# ProjectIMROBLOX
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0-rc.1.

## Client scripts (Studio)

After Rojo sync, under `StarterPlayerScripts → Client` you should see:

- **ClientInit** (LocalScript) — starts the HUD and spell systems
- **GameplayHUDApp**, **SkillControllerApp** (ModuleScripts)
- **CombatController**, **ManaChargeInput**, etc. (LocalScripts)

**Controls:** `F` = lock-on · hold **E** (or key from Keybinds menu) = cast equipped spell · left click = melee only

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "ProjectIMROBLOX.rbxlx"
```

Next, open `ProjectIMROBLOX.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
